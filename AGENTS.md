# AGENTS.md

## Code delegation (mandatory)

All code changes in this repo are executed by **OpenCode** (`opencode run '<task>'`).

- **If you are OpenCode:** write the code.
- **If you are any other agent** (Hermes, Claude Code, Codex, Cursor, etc.): do not write, refactor, or debug code yourself — hand the task to OpenCode and review its output. This applies to every coding task, every session, without being asked.
